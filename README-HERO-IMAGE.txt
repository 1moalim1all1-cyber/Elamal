تغيير صورة الواجهة الرئيسية
=============================
1- افتح alamal-control-7460077.html أو admin.html.
2- افتح قسم «الواجهة الرئيسية».
3- اختر «صورة المنتجات في الواجهة الرئيسية».
4- اضغط «حفظ كل التعديلات».
5- حدّث index.html تحديثًا إجباريًا Ctrl + Shift + R.

الصورة الافتراضية موجودة في: assets/hero-products.jpg
عند تفعيل Firebase Storage تُرفع الصورة وتظهر لكل الزوار. وفي وضع التجربة المحلي تُحفظ داخل المتصفح.
